# PulsePaper

An open source research paper discovery tool for Zotero libraries.

**Documentation:** [English](README.en.md) · [简体中文](README.cn.md)

PulsePaper reads papers from your Zotero library, discovers recent work from selected sources, ranks candidates against your library, and can save recommendations back to Zotero. The application runs as a local Flask web server.

This project is based in part on [zotero-arxiv-daily](https://github.com/TideDra/zotero-arxiv-daily) and retains the GNU AGPL v3 license. See [NOTICE](NOTICE.md).
